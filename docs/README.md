# apollo-c documentation

This folder describes the program as it is: a C transposition of the Apollo 11 flight software (Comanche 055 for the Command Module, Luminary 099 for the Lunar Module), with a yaAGC-compatible simulator, the tests that hold it to the original, and its integration with Virtual AGC and NASSP. Nothing here is a plan, a status report or a diary; each file says what the code does now.

Read in this order. [guide/](guide/README.md) is the reader's guide to the AGC through the C, for someone who knows C and nothing about the AGC. [overview/README.md](overview/README.md) is the system overview and module map, with the [flowcharts](overview/flowcharts/README.md), the AGC-label cross-reference ([xref](overview/xref.md)) and the [NASSP integration design](overview/nassp_integration.md). [modules/](modules/) holds one explanation per module of the program (scope, design, deviations from the AGC, tests, label-to-function tables; the oracle rig, the simulator harness and the NASSP integration included); [overview/oracle-cases.md](overview/oracle-cases.md) lists the yaAGC differential cases and their tolerances; [ARCHITECTURE.md](ARCHITECTURE.md) gives the layout, layering and verification tiers, and [TRANSLATION_GUIDE.md](TRANSLATION_GUIDE.md), [CODING_STANDARD.md](CODING_STANDARD.md), [NAMING.md](NAMING.md) and [TIPS.md](TIPS.md) give the rules and lessons of the translation. Then the code in `src/`. How the project was made is in the git log.
