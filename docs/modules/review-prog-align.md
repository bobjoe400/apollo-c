## Lessons

* A guard that "checks the previous job did its work" (THETAD == 0 after P51ZERO) hides a missing step: the LM P51 never zeroed THETAD, and the guard turned every P51 after a P52 into BAD_ARG.  Read the AGC for the step, not the guard.
* RP-TO-R / R-TO-RP pick the body by BHIZ on MPAC, and at most call sites MPAC is the time just pushed: the moon, whatever LUNAFLAG says.  Check what MPAC holds at an interpretive CALL before mapping a mode argument to a flag.
* BZF / BZMF after DCA or DXCH test only A, the major word: a DP compare against zero in C is not the same test.
* A status return that only ever says OK spreads: every caller grows an `if (st != OK)` that hides real failures next to it (align_stall_outcome's callers swallowed BAD_ARG this way).  Make never-fail routines void or value-returning first, then the real failure paths stand out.
* For prolog work: an AGC label index (label -> rope, file, page) built from the listings' "# Page" markers gives exact cites automatically; several hand-written page numbers in this lane were off by up to five pages (e.g. MKVB51 is p. 232, not 227).
