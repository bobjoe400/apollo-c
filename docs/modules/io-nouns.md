# io-nouns -- PINBALL noun tables (PINBALL_NOUN_TABLES.agc, CSM + LM)

## Scope
Comanche055 pp. 268-284, Luminary099 pp. 301-319. Files: include/agc/io/nouns.h,
src/io/dsky/nouns/tables_csm.c, noun_tables_lm.c, noun_scales.c, noun_data.c,
tests/io/nouns.c. The tables were generated by a script from the AGC text
(not kept in the tree); every OCT word, and the 2DEC conversions in
SFINTAB/SFOUTAB, was checked against the assembled ropes in
tools/oracle/ropes (NNTYPTAB, RUTMXTAB, mixed NNADTAB, SFINTAB, SFOUTAB all
match word for word).

## Design table
| AGC table / routine | C | Notes |
|---|---|---|
| NNADTAB + NNTYPTAB + IDADDTAB + RUTMXTAB | `agc_noun_table_csm[100]`, `agc_noun_table_lm[100]` | one flat `agc_noun_t` per noun; entry n has .noun == n; spare nouns ncomp == 0 |
| (SF routine, SF constant) pairs | `agc_scale_t` + `scale_defs[]` | named after the quantity; letter A..AAA from ASSEMBLY_AND_OPERATION_INFORMATION |
| SF ROUTINE CODE list | `agc_sf_routine_t` | codes 6 and 13 differ per vehicle |
| SFINTAB / SFOUTAB | `sfintab_*`, `sfoutab_*` (noun_scales.c) | octal word pairs, per vehicle (LM has 29 constants, CSM 20) |
| GTSFIN / GTSFOUT | `agc_scale_sfconst` | pair decoded to agc_dp_t (hi*2^14+lo, 1s complement words) |
| LODNNTAB | `agc_noun_lookup`, `agc_noun_lookup_vehicle` | NOT_FOUND for spare nouns, BAD_ARG for noun >= 100 |
| ECADRs | `agc_noun_data_t` (204 erasable ids + 4 special) | `agc_noun_read/write` |

Decoding rules (verified on all 200 table rows):
* Normal nouns 00-39: NNTYPTAB = component code (bits 15-11: 00000/1/2 = 1/2/3 comp,
  bit 4 dec only, bit 5 no load), SF routine (10-6), SF constant (5-1), shared by all
  components. Components 2,3 are the following erasable words (CDUX,CDUY,CDUZ ...).
* Mixed nouns 40-99: NNADTAB = component code (top 5 bits) + IDADDTAB index (low 10
  bits, = 3*(noun-40)); NNTYPTAB = three 5-bit SF constants, RUTMXTAB = three 5-bit SF
  routines, component 1 in the low field.
* HMS nouns: a single DP word across R1-R3; data_id[0] only (see header).
* Nouns 01-03, 10, 15 (NNADTAB OCT 40000/77776/77777): special ids, resolved by pinball.
* LM noun 66 component 2 (IDADDTAB OCT 0, scale TT): data id CHANNEL33, read raw from
  channel 33.

## Value conventions (agc_noun_read/write)
DP erasable: the agc_dp_t. SP: SP word in the high word (agc_dp_from_sp / agc_dp_high).
SP raw (scales OCTAL, CDU_DEG, CDU360, Y_OPTICS_DEG, LR_POSITION, which use all 15
bits): the unsigned word 0..0x7FFF as an integer, because 0o77777 must stay an angle
and not become -0. `agc_scale_info().is_dp/is_raw` tells pinball which.

## Deviations
* `noun_data_access` is the single dispatch switch, but the accessor calls sit in
  per-family helpers (time, SP words, raw words) to respect the 60-line rule.
* Descriptions in the table comments come from the NNADTAB comments (identical to the
  ASSEMBLY_AND_OPERATION_INFORMATION noun list apart from transcription typos), sentence-cased.
* Where one display buffer word is used as SP by some nouns and DP by others
  (DSPTEM1, DSPTEM2 +1, DSPTEMX) the DP uses get ids with a `_DP` suffix.
* Aliases keep separate ids as the tables name them (DSPTEMX = DSPTEM2 +1, OPTIONX = DSPTEMX).
* OPTION2 is used raw (noun 06) and as WHOLE (CSM noun 72); treated as raw.
* Table typos in the AGC comments (OCATAL, DPDEG(360 ...) are ignored; the octal words rule.
* CSM nouns 6 / LM noun 06: CSM 2 comp, LM 3 comp (OPTION1..3) exactly as the tables say.

## Noun write-path gaps

_Merged from the review-io-dsky review note (see the git history); the loadable components that cannot be written._

Loadable (no NNTYPTAB no-load bit) components whose read works but whose
write returns NOT_FOUND from agc_dispatch_noun (src/exec/nouns.c, not this
lane): the values are computed on read (noun_derived) or owned by a
module that exposes a reader only.
* CSM: N17/N96 CPHIX..+2, N38 TET, N49 DELTAR/DELTAV/source code, N51
  RHOSB/GAMMASB, N55 NN1, N62 HDOT/ALTI (P11 readout), N87/N94 MRKBUF1+3/+5,
  N95 PRAXIS..+2.
* LM: N18 FDAIX..Z, N38 TET, N49 DELTAR/DELTAV/WHCHREAD, N51 ALPHASB/BETASB,
  N55 NN, N67/N78 RSTACK words, N80 DATAGOOD/OMEGAD.
In the AGC a V21/V25 on these stores into the erasable; in C the load
stops with NOT_FOUND. All are displays the programs overwrite (FDAI
angles, mark buffers, P11 readout, TET) except N55 NN/NN1 (P34/P35
iteration count, which the crew may load) -- see Requests.

## Program flow and decisions

_Documentation wave (2026-10-12); prose and tables brought to the final tree (HEAD 3b97dc8) by the final pass (2026-10-14). The prose was written by reading the code; the two tables were extracted from the function bodies (flag, alarm, channel and scheduling calls; `agc_erase_*` accessors) and list only what the code does. Files: `src/io/dsky/nouns/*.c`, `src/exec/nouns.c`._

The noun tables are data; the decisions are how a noun component is
found, scaled and stored.

* **Lookup** (`src/io/dsky/nouns/data.c:agc_noun_lookup`,
  `agc_noun_lookup_vehicle` = LODNNTAB): the flat `agc_noun_t` row for
  the flown rope (`tables_csm.c`, `tables_lm.c`: NNADTAB / NNTYPTAB for
  normal nouns 00-39 with one SF pair for all components, IDADDTAB /
  RUTMXTAB for mixed nouns 40-99 with a pair per component, plus the
  NO-LOAD and decimal-only bits pinball tests in NOUNTEST / PREDSPAL).
* **Data access** (`data.c:noun_data_access`, through `agc_noun_read` /
  `agc_noun_write`): one switch on the data id. Core erasables are served
  here (times `noun_access_time`, SP masses and PIPAs `noun_access_sp`,
  raw CDU / DAPDATR / FAILREG / THETAD words `noun_raw_read` /
  `noun_raw_write`, OPTION1-3, SAMPTIME, T3TOT4, RR-AZ/ELEV); the
  machine-address nouns 01-03, 10, 15 are NOT_FOUND here because pinball
  resolves them by ECADR (`src/core/ecadr.c`); every other id goes to
  `src/exec/nouns.c:agc_dispatch_noun`.
* **Owner dispatch** (`src/exec/nouns.c:agc_dispatch_noun`): a DP field of
  a guidance / entry / landing / alignment state block (`noun_dp`,
  per vehicle), else an SP field (`noun_sp`, stored in the high word),
  else a raw 15-bit word (`noun_word`), else a computed component
  (`noun_by_function`: derived values, star codes `noun_star_code`,
  lat/long `noun_latlong`, the P11 readout `noun_p11_readout`). One
  vehicle- and mode-dependent case: VMAGI in CSM P11 (MODREG 11) is the
  P11 readout's, not the guidance erasable. An id no owner holds is
  NOT_FOUND. Value convention (include/agc/io/nouns.h): SP in the high
  word of the `agc_dp_t`, DP as the value, raw words unscaled.
* **Scales** (`scales.c:agc_scale_info`, `agc_scale_sfconst` = GTSFIN /
  GTSFOUT): the SF routine and SF constant words of SFINTAB / SFOUTAB per
  scale type, as the assembled rope words; an unknown scale or SF code is
  BAD_ARG. Pinball's `scale.c` and `sfin.c` (io-pinball) do the display
  and load conversions with them.
