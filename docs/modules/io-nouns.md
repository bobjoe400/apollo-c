# io-nouns -- PINBALL noun tables (PINBALL_NOUN_TABLES.agc, CSM + LM)

## Scope
Comanche055 pp. 268-284, Luminary099 pp. 301-319. Files: include/agc/agc_nouns.h,
src/io/noun_tables_csm.c, noun_tables_lm.c, noun_scales.c, noun_data.c,
tests/test_nouns.c. The tables were generated by a script from the AGC text
(not kept in the tree); every OCT word, and the 2DEC conversions in
SFINTAB/SFOUTAB, was checked against the assembled ropes in
tools/oracle/ropes (NNTYPTAB, RUTMXTAB, mixed NNADTAB, SFINTAB, SFOUTAB all
match word for word).

## Design table
| AGC table / routine | C | Notes |
|---|---|---|
| NNADTAB + NNTYPTAB + IDADDTAB + RUTMXTAB | `agc_noun_table_csm[100]`, `agc_noun_table_lm[100]` | one flat `agc_noun_t` per noun; entry n has .noun == n; spare nouns ncomp == 0 |
| (SF routine, SF constant) pairs | `agc_scale_t` + `scale_defs[]` | named after the quantity; letter A..AAA from ASSEMBLY_AND_OPERATION_INFORMATION |
| SF ROUTINE CODE list | `agc_sf_routine_t` | codes 6 and 13 differ per vehicle |
| SFINTAB / SFOUTAB | `sfintab_*`, `sfoutab_*` (noun_scales.c) | octal word pairs, per vehicle (LM has 29 constants, CSM 20) |
| GTSFIN / GTSFOUT | `agc_scale_sfconst` | pair decoded to agc_dp_t (hi*2^14+lo, 1s complement words) |
| LODNNTAB | `agc_noun_lookup`, `agc_noun_lookup_vehicle` | NOT_FOUND for spare nouns, BAD_ARG for noun >= 100 |
| ECADRs | `agc_noun_data_t` (204 erasable ids + 4 special) | `agc_noun_read/write` |

Decoding rules (verified on all 200 table rows):
* Normal nouns 00-39: NNTYPTAB = component code (bits 15-11: 00000/1/2 = 1/2/3 comp,
  bit 4 dec only, bit 5 no load), SF routine (10-6), SF constant (5-1), shared by all
  components. Components 2,3 are the following erasable words (CDUX,CDUY,CDUZ ...).
* Mixed nouns 40-99: NNADTAB = component code (top 5 bits) + IDADDTAB index (low 10
  bits, = 3*(noun-40)); NNTYPTAB = three 5-bit SF constants, RUTMXTAB = three 5-bit SF
  routines, component 1 in the low field.
* HMS nouns: a single DP word across R1-R3; data_id[0] only (see header).
* Nouns 01-03, 10, 15 (NNADTAB OCT 40000/77776/77777): special ids, resolved by pinball.
* LM noun 66 component 2 (IDADDTAB OCT 0, scale TT): data id CHANNEL33, read raw from
  channel 33.

## Value conventions (agc_noun_read/write)
DP erasable: the agc_dp_t. SP: SP word in the high word (agc_dp_from_sp / agc_dp_high).
SP raw (scales OCTAL, CDU_DEG, CDU360, Y_OPTICS_DEG, LR_POSITION, which use all 15
bits): the unsigned word 0..0x7FFF as an integer, because 0o77777 must stay an angle
and not become -0. `agc_scale_info().is_dp/is_raw` tells pinball which.

## Deviations
* `noun_data_access` is the single dispatch switch, but the accessor calls sit in
  per-family helpers (time, SP words, raw words) to respect the 60-line rule.
* Descriptions in the table comments come from the NNADTAB comments (identical to the
  ASSEMBLY_AND_OPERATION_INFORMATION noun list apart from transcription typos), sentence-cased.
* Where one display buffer word is used as SP by some nouns and DP by others
  (DSPTEM1, DSPTEM2 +1, DSPTEMX) the DP uses get ids with a `_DP` suffix.
* Aliases keep separate ids as the tables name them (DSPTEMX = DSPTEM2 +1, OPTIONX = DSPTEMX).
* OPTION2 is used raw (noun 06) and as WHOLE (CSM noun 72); treated as raw.
* Table typos in the AGC comments (OCATAL, DPDEG(360 ...) are ignored; the octal words rule.
* CSM nouns 6 / LM noun 06: CSM 2 comp, LM 3 comp (OPTION1..3) exactly as the tables say.

## Stubs
None in the tables. `agc_noun_read/write` return AGC_STATUS_UNIMPLEMENTED for the ids
listed next (core has no accessor yet).

## Requested core additions
Wired already (core accessors exist): TIME2, TIG, TTOGO, TTPI, PIPAX/Y/Z, CSMMASS, LEMMASS,
CDUX/Y/Z, CDUS, CDUT, DAPDATR1/2, FAILREG(+1,+2), THETAD(+1,+2), CHANNEL33.

Wanted: for each id below, `<agc_dp_t|agc_sp_t|uint16_t> agc_erase_<lowercase name>(void)`
and `void agc_erase_set_<name>(...)` (raw words as uint16_t, SP as agc_sp_t, DP as agc_dp_t,
the AGC scale kept as is). "X +n" ids are the n-th word after X (suffix _Pn); vectors such as
DELVLVC / +2 / +4 may be one agc_vec_t accessor plus component access. Note some of
these may already exist under other names in agc_erasable.c (e.g. DELVSLV vs DELVLVC:
identical storage in Comanche, separate in Luminary -- not wired for that reason; TET is
the time of the state vector being integrated, not PIPTIME).
