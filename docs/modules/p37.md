# p37 -- P37 return to earth (Comanche055 P37_P70.agc, pp. 890-933)

## Scope
Comanche only. The whole of P37_P70.agc: the P37 program (displays, conic
search, precision search, targeting for P40/P41) and its subroutines.
XT1LIM was translated by guid-entry; its public wrapper is kept, the body is
re-done with the real index register (see Deviations). The file holds no P70
code in Comanche (the title is shared with Luminary's P70; see the header of
return_to_earth.c and docs/modules/guid-entry.md).

AUGEKUGL (P30-P37.agc pp. 644-647, the entry range/time fit used by RTEDISP)
is not translated anywhere in the tree; a local copy is kept here
(return_to_earth_conic.c) until guidance exports it.

Files (all src/csm/burns/):
* return_to_earth.c            jobs: P37 .. RTE299 entry, RTEVN displays, RTE505,
                               P37G/P37N..P37W targeting, P370ALRM; module erasables
* return_to_earth_conic.c      INVC109, RTE317..RTE390 conic search, TMRAD100,
                               RTEDISP (+ AUGEKUGL local copy)
* return_to_earth_velocity.c   V2T100, GAMDV10, DVCALC, XT1LIM (pure arithmetic)
* return_to_earth_precision.c  PREC100..PRECX, RTENCK1/2/3 (integration)
* return_to_earth_internal.h   module erasables struct, prototypes between the files
* return_to_earth_pending.h    job ids and other lanes' symbols not yet published
* tests/test_return_to_earth.c coplanar conic return case
